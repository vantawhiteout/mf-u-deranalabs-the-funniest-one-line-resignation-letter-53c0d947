The Funniest One-Line Resignation Letter

## Run it

Requires Node 22.18 or later (TypeScript runs natively).

```sh
node main.ts
```

`main.ts` writes the single resignation letter to `/output/entry.txt` as UTF-8 text.
The line is a fixed constant; the program is deterministic and writes no other output.
